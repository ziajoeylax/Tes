# VEXO Dashboard

نسخه آماده اجرا روی Railway و سرویس‌های Node.js.

## اجرا

```bash
npm start
```

سرور به صورت خودکار از `PORT` محیط استفاده می‌کند و روی `0.0.0.0` گوش می‌دهد.

## شخصی‌سازی

مشخصات قابل تغییر در فایل `public/config.js` قرار دارند:

- نام پنل
- نام کاربر
- سطح کاربری
- IP سرور
- نسخه پنل
- متن خوش‌آمدگویی
- متن پشتیبانی

## Railway

پروژه را به GitHub آپلود کن و در Railway همان Repository را Deploy کن. نیازی به تعیین پورت دستی نیست؛ Railway مقدار `PORT` را در اختیار برنامه قرار می‌دهد.

Health check:

`/health`
